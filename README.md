# Ainalym — затқа жаңа айналым

Қазақша оқу тапсырмасы үшін жасалған қолданылған заттар маркетплейсінің статикалық сайты. HTML, CSS және JavaScript қолданылады; сыртқы кітапханалар қажет емес. Тапсырмадағы төрт негізгі бетке байланыс пен құпиялылықтың екі қосымша беті қосылды.

## Дайын сайтты ашу

`dist/index.html` файлын браузерде тікелей ашуға болады. Жергілікті сервер арқылы қарау үшін Node.js 18 немесе одан жаңарақ нұсқа қажет. Терминал `sss` бумасында ашылған болса, алдымен `package.json` орналасқан `ainalym` бумасына өтіңіз:

```powershell
cd .\ainalym
npm start
```

Терминал жолы `...\sss\ainalym>` болса, тек `npm start` орындаңыз. Браузерде `http://localhost:4173` мекенжайын ашыңыз. Сайтты пайдаланған кезде терминалды ашық ұстаңыз. Тәуелділік орнату қажет емес. Серверді тоқтату үшін `Ctrl+C` басыңыз.

## Қайта құрастыру және тексеру

Бастапқы файлдарды өзгерткеннен кейін дайын HTML мен ресурстарды жаңартыңыз. Бұл командаларды да `ainalym` бумасының ішінде орындаңыз:

```sh
npm run build
npm run check
```

Бұл командалар `scripts/build.mjs` және `scripts/verify.mjs` файлдарын іске қосады. Тексеруді тікелей `node scripts/verify.mjs` арқылы да орындауға болады. Дайын нәтиже `dist` бумасында орналасады.

## Беттер

| Файл | Мазмұны |
| --- | --- |
| `index.html` | Басты бет, тауарлар және жалпы ұсыныс |
| `seller.html` | Сатушыға арналған жариялау шарттары |
| `advantages.html` | Платформаның артықшылықтары |
| `buyer.html` | Сатып алушыға арналған ақпарат |
| `contacts.html` | Байланыс формасы, үлгі жұмыс уақыты және карта |
| `policy.html` | Осы оқу нұсқасының дерек өңдеуін түсіндіру |

## Мәтін мен сілтемелерді өзгерту

Бет үлгілері `src/pages/*.mjs` ішінде. `media-files/texts` бумасында бастапқы мәтіндік материалдар сақталған; олар HTML-ге автоматты түрде қосылмайды. Мәтіндерді өзгерткенде тиісті бет үлгісін де жаңартыңыз.

Негізгі әрекет сілтемелері `src/site.config.mjs` файлында басқарылады:

```js
links: {
  publish: 'seller.html',
  view: 'buyer.html',
}
```

Осы мәндерді өзгертіп, `npm run build` орындаңыз. Жаңа мәндер дайын HTML сілтемелеріне және браузердегі қолданба конфигурациясына енгізіледі. Түймелердің негізгі және қосымша көрінісі `data-type="primary"` / `data-type="secondary"` атрибуттары арқылы анықталады. Мәзірдің ішкі тармақтары CSS арқылы меңзерді апарғанда немесе пернетақта фокусы түскенде ашылады; ол үшін JavaScript қажет емес.

## Медиа және SEO

Тапсырмадағы `media-files` бумасы берілмегендіктен, суреттер, иллюстрациялық карта және мәтіндік материалдар осы жоба үшін жасалды. Құрастыру кезінде қажетті ресурстар `dist/media-files` бумасына көшіріледі. Пікірлер сайтта үлгі ретінде белгіленген. Көрсетілген 250/400/550 ₸ бағалары мен 1–30 күн шарттары — оқу үшін алынған үлгі мәндер.

Беттерде жеке тақырыптар, сипаттамалар және Open Graph метадеректері бар. `sitemap.xml` және `robots.txt` құрастыру кезінде жасалады. Сайтты нақты доменге орналастыру алдында `src/site.config.mjs` ішіндегі `baseUrl` мәнін өз доменіңізге ауыстырып, қайта құрастырыңыз.

## Байланыс формасының шектеуі

Форма міндетті өрістерді тексеріп, ат, электронды пошта және хабарлама бар `.txt` файлын жүктеуді ұсынады. «Хабарламаны жүктеу» түймесі үшін JavaScript қосулы болуы керек. Форма хабарды серверге жібермейді, пошта қолданбасын ашпайды және жіберілді деген жалған хабар көрсетпейді. Жүктелген мәтінді әрі қарай пайдалану пайдаланушының өз қолында. `hello@ainalym.example` — жұмыс істемейтін үлгі мекенжай. Нақты хабар қабылдау үшін шынайы байланыс арнасын және серверлік өңдеуді қосу қажет. Қазіргі сайтта тіркеу, төлем, аналитика немесе localStorage арқылы сақтау жоқ. Құпиялылық беті осы оқу нұсқасын сипаттайды; нақты сервис іске қосылғанда оны қайта дайындау керек.
